A tiny browser game built by an AI agent from **one prompt**:

> Build me a tiny browser game: a little ghost collects stars and dodges bats.
> Arrow keys to move. 60 seconds on the clock. 3 lives.

## The game

Open [`game.html`](game.html) in any browser. Move with arrow keys / WASD,
collect stars (+10), dodge the bats, survive 60 seconds with 3 lives.
Press **D** for autopilot demo, **R** to restart.
